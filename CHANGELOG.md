# Changelog

## v0.1.0 — 2026-10-05

### Added
- Initial LouderMe Android project foundation.
- Product identity and package `com.realmichelduarte.louderme`.
- Quick boost UI for 100%, 125%, 150%, 175%, and 200%.
- Mixer / EQ entry point.
- Smart Boost Beta entry point.
- In-app About screen with build-derived version.
- Permanent project audit log, architecture notes, and project protocol.
- Proprietary license.

### Known limitations
- The system-wide audio amplification engine is not implemented or validated yet.
- Boost buttons currently represent the planned controls and do not yet alter audio.
- Mixer / EQ and Smart Boost are placeholders in this foundation release.

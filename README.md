# LouderMe

**Make everything louder.**

LouderMe is an Android-first audio booster focused on increasing the perceived loudness of the phone's general audio output, with quick boost levels, mixer/EQ presets, and an experimental Smart Boost mode.

## Product priorities

1. Global phone audio boost is the core feature.
2. One-tap boost levels: 100%, 125%, 150%, 175%, and 200%.
3. Manual fine adjustment.
4. Mixer / EQ and saved presets.
5. Presets optimized for dialogue, movies, podcasts, bass, speaker, and headphones.
6. Smart Boost is experimental and must remain secondary to reliable manual boosting.
7. The app must clearly indicate whether the global processing engine is actually active.

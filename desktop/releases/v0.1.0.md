# LouderMe Desktop v0.1.0

First stable Windows release of **LouderMe Desktop** by Michel's Lab.

## Downloads
- `LouderMe-Setup-v0.1.0.exe` — recommended Windows installer.
- `LouderMe-v0.1.0.exe` — self-contained portable build.
- Matching `.sha256` files — release integrity checks.

## What's included
- Native .NET 10 / WinForms desktop application; no browser or WebView UI.
- Official LouderMe Option 4 identity.
- Windows output-device detection, master volume and mute.
- **Global Boost 100–250%** using real post-mix digital gain through the Windows APO effects path.
- 250% corresponds to a target digital gain of approximately **+7.96 dB**.
- Seven-band equalizer with LouderMe's Android-compatible bands and presets.
- Opt-in **Start LouderMe with Windows**.
- Inno Setup installation and uninstall support.

## One-time system-wide boost setup
Windows' normal endpoint volume ends at 100%. LouderMe uses **Equalizer APO 1.4.2 x64** for system-wide processing above 100%.

LouderMe does not bundle or redistribute Equalizer APO. Use the **Get system-wide engine** button in LouderMe to open the official project page, install it, select the intended playback device in Configurator, and reboot if the installer requests it.

Official Equalizer APO 1.4.2 x64 SHA-256:
`7403be7427bbe1936a40dded082829b6e217fc4f5990fee5cba501f0ae055afa`

## Compatibility
- ASIO and WASAPI exclusive-mode playback can bypass Windows system effects and therefore bypass the LouderMe APO boost.
- Positive digital gain consumes headroom and can trigger limiting/compression or distortion depending on source material and hardware.

## Integrity and signing
The LouderMe v0.1.0 Windows release publishes SHA-256 checksums for both executable files.

Windows Authenticode publisher signing is **not configured yet** for this first Desktop release, so Windows SmartScreen can warn on first launch/installation even when the downloaded file matches the published SHA-256.

## Validation status
Repository CI validates compilation, the 100–250% gain contract, APO configuration generation, installer creation and checksums. Physical audible validation on the target Windows machine is still a separate device-level test.

# LouderMe Desktop v0.1.1

Stable Windows release by **Michel's Lab**.

## What's new
- Completes the native Windows LouderMe visual identity with the canonical flowing-waveform header and official **SOUND THAT LIFTS YOU** tagline.
- Adds a branded native startup splash.
- Replaces the old text-only About experience with a dedicated native About surface.
- About now includes the current canonical Michel Duarte portrait, official Michel's Lab lockup and Instagram/Facebook/LinkedIn/GitHub/Email rows with visible network names.
- Adds waveform-derived Global Boost activity and EQ-curve visualization.
- Adds an in-app stable updater connected to `louderme-desktop/latest.json`.
- The updater downloads only a newer published installer, verifies the manifest SHA-256 and only then asks Windows to launch the installer.
- Keeps native 0–100 Windows endpoint volume separate from APO-backed Global Boost 100–250%.
- Preserves opt-in **Start LouderMe with Windows**.

## System-wide boost dependency
System-wide gain above the native Windows endpoint maximum still uses user-installed **Equalizer APO 1.4.2 x64**.

LouderMe does not redistribute Equalizer APO. ASIO and WASAPI exclusive-mode playback can bypass Windows system effects.

## Integrity / Windows trust
The installer and portable EXE are published with SHA-256 checksum files.

Windows Authenticode publisher signing is still not configured, so SmartScreen can warn even when the downloaded file matches the published checksum.

## Validation boundary
CI validates the native build, branding/About/splash/updater contract, 100–250% APO configuration contract, portable EXE, Inno Setup installer and checksums.

Physical endpoint attachment, reboot behavior and audible 100/150/200/250% validation remain real-Windows-machine checks.

# LouderME Desktop v0.1.11

Michel's Lab coordinated stable Windows release. Windows advances from v0.1.5 to v0.1.11 to align identifiers with Android for this release.

## Included
- Native Windows WinForms utility with endpoint volume/mute, seven-band equalizer, and **Equalizer APO-backed** 100–250% Global Boost.
- Fixed top-bar About access, canonical Michel's Lab identity, checked installer and updater behavior.
- Clean Inno Setup installer, optional portable app and SHA-256 checksums.

## Engineering progress (not shipped as active audio routing)
- Experimental Windows C++ gain/EQ/limiter and PCM16/float32 44.1/48/96 kHz user-mode bridge now pass synthetic CI tests.
- A SysVAD-derived unsigned lab driver passed Windows WDK INF/CAT validation.
- The experimental driver, its installation logic and native routing bridge are **not bundled or activated** in this stable Windows app.
- LouderME does **not** yet intercept and process the original OS-wide render stream through its own replacement driver; Equalizer APO is still required for stable Global Boost above 100%.

## Artifacts
- `LouderMe-Setup-v0.1.11.exe` — recommended.
- `LouderMe-Portable-v0.1.11.exe` — optional.
- Corresponding `.sha256` files.

## Validation boundary
Source CI and installed-Windows smoke tests are mandatory before publication. Physical playback behavior, APO attachment to particular hardware, driver signing and native-loopback routing remain real-device checks. Publisher Authenticode signature is not claimed.

# LouderMe Desktop v0.1.12 — maintenance release

Michel's Lab Windows maintenance package. This is an Equalizer APO-backed Windows build, **not** a native universal virtual-driver audio replacement.

## Included
- Windows output device master volume/mute (0–100%) separate from 100–250% Boost.
- Seven-band EQ and presets, existing native WinForms Michel's Lab UI and About.
- Installer publisher/support/update links point only to Michel's Lab and the dedicated `michels-lab/LouderME-Releases`.
- Stable desktop updater rejects cross-app or malformed manifests, non-HTTPS/foreign asset links, version mismatches and malformed checksum metadata. Downloads still require SHA-256 verification.
- Automatic publisher-isolation regression checks run during normal Windows builds and before stable publication.

## Engineering improvements in source (NOT active global driver in this installer)
- LouderMe-owned experimental C++ PCM DSP has bounded limiter, 5 ms gain/EQ bypass transitions and dual-filter crossfades for live EQ band changes; rapid on/off changes preserve live filter history.
- Windows/Linux portable DSP and managed PCM bridge synthetic CI tests verify these engineering milestones.
- Experimental SysVAD driver is not delivered, installed, enabled or signed as part of this stable app. No native system-wide routing or physical audio result is claimed.

## Published artifacts
- `LouderMe-Setup-v0.1.12.exe` — recommended installer.
- `LouderMe-Portable-v0.1.12.exe` — optional portable build.
- SHA-256 sidecars for both files.

## Validation
- Windows build, silent installation/launch/uninstall, compact-layout and actual installed Home/About screenshot integrity gates must pass before publication.
- Physical audio device testing, Equalizer APO compatibility and publisher Authenticode signature remain separate; unsigned Windows installer may trigger SmartScreen.

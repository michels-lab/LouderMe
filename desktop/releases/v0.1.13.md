# LouderMe Desktop v0.1.13 — Windows audio activation diagnostic release

**Owner validation build (2026-10-12).** Installs as a normal Windows app via the official LouderME release channel. The owner's v0.1.12 report is that the app opens and sliders respond but Boost and EQ have no audible effect. This build improves activation and offers an actual listening test; do **not** interpret it as proof that Windows system audio is already amplified.

## Included
- Moving Boost above 100% automatically enables Boost; changing an EQ band or selecting a preset enables EQ.
- If Equalizer APO is absent, Boost and EQ controls no longer pretend to function. Windows device volume (0–100%) remains available.
- Checks that Equalizer APO has an *active* LouderMe include, that the managed file exists, and that its contents match the displayed settings. Differentiates unavailable, not applied and on-disk configured states without claiming acoustic success.
- One-time, explicitly consented **Connect Boost/EQ (Windows setup)** action requests Windows administrator approval to link the managed configuration. Backs up the original config and grants the current user write access to `LouderMe.txt` only; does not change the default audio endpoint.
- Optional **Test audio path (-18 dB temporarily)** action reduces configured sound for four seconds, restores the prior settings and asks whether the actual output became quieter. This is a listening test, not an automated acoustic measurement.
- **Copy audio diagnostics** includes the selected Windows device and APO configuration/owner-reported listening-test status.
- Maintains the official LouderMe design, About, updater and Windows installer.

## Important limits
- **Equalizer APO is still required for Windows system-wide Boost/EQ.** Install it, select your *actual playback device* in Equalizer APO Configurator, then restart Windows if requested.
- The experimental Michel's Lab C++ DSP and unsigned SysVAD virtual driver are *not* delivered or attached to global Windows playback in this build.
- Exclusive-mode/ASIO audio can bypass system effects. A 250% slider value is requested digital gain, not verified loudness or dB SPL; positive gain can clip/compress.
- Real physical-device A/B processing, output compatibility and Windows Authenticode publisher-signature validation remain outstanding. Windows SmartScreen may warn about an unsigned installer. No Play Store or Android code release in this Windows-only version.

## Distribution and QA
- Recommended: `LouderMe-Setup-v0.1.13.exe`; optional portable: `LouderMe-Portable-v0.1.13.exe`; SHA-256 sidecars provided.
- Windows build, executable APO contract tests, actual install/startup/uninstall, fixed About/scroll and installed Home/About rendered-UI evidence must pass in release CI before publishing.
- Official public unified bundle retains **Android v0.1.12** alongside **Windows v0.1.13**; each app keeps its own version and updater.

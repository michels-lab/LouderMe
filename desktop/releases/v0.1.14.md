# LouderMe Desktop v0.1.14 — safer Windows audio-path diagnostics

**Stable Windows maintenance update.** This patch improves the existing Equalizer APO-based desktop app's four-second listening diagnostic. It is NOT the experimental Michel's Lab native virtual audio driver and does not certify system-wide audio processing on the owner's speakers.

## What changed from v0.1.13

- **Interrupted −18 dB test recovery:** on next app launch, detect and restore an *exact*, LouderMe-generated temporary attenuation left by a forced close/crash. The previous four-second diagnostic restored only when its normal `finally` cleanup ran.
- **Protect other Equalizer APO configurations:** if someone or another program edits the tagged temporary file, LouderMe refuses to silently overwrite it and displays a recovery warning. Files with unrecognized content remain untouched.
- **Existing installs:** recover the legacy unmarked v0.1.13 diagnostic only if the entire file exactly matches the saved LouderMe configuration plus the known temporary −18 dB suffix. This does not remove a deliberate third-party −18 dB filter.
- **Atomic test intent:** take a private snapshot of current Boost and seven EQ bands, disable Boost/EQ interaction while the short test is active, and restore against that snapshot even if unrelated UI events occur.
- **Preserve the public product:** default Windows endpoint volume, branded Home/About design, updater, audio-status truthfulness, and separately launched Developer Edition remain unchanged.

## Verification required for a published stable build

The original recovery implementation merged as [PR #101](https://github.com/michels-lab/LouderMe/pull/101), with Windows .NET/installed-installer/APO regression CI and Android non-regression CI passing. This v0.1.14 versioned package itself must pass **new exact-head** release CI, including `--check-apo-contract` negative fixtures, Developer audits, actual installer startup/uninstall, Home/About rendered evidence and SHA-256 checksums before publication. The release should not be represented as available unless those tests and a real GitHub tag/assets exist.

## Explicit limits

- Windows Boost and EQ still require a correctly installed and attached **Equalizer APO** on the actual playback device. The 100–250% slider represents requested digital gain, not a verified increase in acoustic output.
- A physical -18 dB audible listening comparison on the owner's actual speakers/headphones was not performed by CI. The tool cannot recover a crash until LouderMe is launched again; it also cannot safely overwrite a conflicting external edit.
- The experimental native C++ DSP and unsigned SysVAD lab driver are not part of this Windows installer. Real system-wide native audio and third-party Windows-app playback remain unverified under [issues #46](https://github.com/michels-lab/LouderMe/issues/46) and [#48](https://github.com/michels-lab/LouderMe/issues/48).
- Windows installers may trigger SmartScreen because Authenticode publisher signing is not yet established. No new Android APK or Android signing identity is created by this Windows-only maintenance version.

**Distribution:** Windows Setup `LouderMe-Setup-v0.1.14.exe` and optional Portable `LouderMe-Portable-v0.1.14.exe`, with matching SHA-256 sidecars, only after verified stable source release. The official unified public release retains Android v0.1.12.

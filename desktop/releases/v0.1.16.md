# LouderMe Desktop v0.1.16 — restored About and interactive 7-band equalizer

**Stable Windows visual-maintenance update.** Fixes three owner-reported usability regressions present in v0.1.15. No changes to Android, audio processing coefficients, Windows endpoint routing, or the experimental native driver.

## What is fixed

- **About no longer collapses or clips:** all four About sections now keep proper width, measured content height and scrolling at 600×520 and 900×700. The logo, product information, author portrait, studio name, links, update and privacy/third-party information remain visible and usable. First open starts at the product hero instead of unexpectedly scrolling halfway down. Real runtime layout checks reject clipping of the logo and horizontal text.
- **Official LouderMe identity on dark UI:** the approved Option 4 LouderMe waveform/wordmark is derived straight from the canonical project SVG, preserving wave geometry and blue/gold accents; only the dark-navy wordmark and caption colors are adapted for contrast. The result is transparent and integrated with the dark application theme, not displayed on a white pasted-on rectangle. The approved Windows application icon is retained.
- **A genuinely interactive EQ:** the larger seven-node curve displays frequencies, +10/0/−10 dB guides and individual dB values. Dragging a node moves the associated numeric setting in 0.5 dB steps through the original preset/Custom and Equalizer APO application logic; preset changes update the graph. The previously working numeric controls are kept, not replaced by an untestable visual mockup.
- **Studio branding artifact removed:** the Michel's Lab author section no longer draws a magenta rectangle over the source lockup; native MICHEL'S LAB text displays with the portrait, title and clickable socials.

The Windows visual evidence manifest binds the screenshots to the actual built EXE SHA-256, not a made-up static mockup.

**The exact v0.1.16 release-source SHA must pass its own** installer build/launch, executable metadata, About/EQ visual-capture contract, Developer and APO tests, and checksum creation before assets are published. Release is not considered public until `desktop-v0.1.16` and the independent Michel's Lab unified distribution pass immutable SHA/asset checks.

## Important limitations

Windows Global Boost/EQ still depend on correctly attached user-installed **Equalizer APO**. The interactive graph edits a real 7-band configuration, but the audio-path outcome on the owner's hardware has not been acoustically measured. An unconfigured device does not gain system-wide effects simply because the graph can be drawn. The unsigned/experimental virtual driver remains unshipped and still needs actual Windows device proof. No Android APK is re-signed or modified. This is a stable maintenance version, not a release candidate.

**Expected Windows assets:** `LouderMe-Setup-v0.1.16.exe`, `LouderMe-Portable-v0.1.16.exe` and their two separate `.sha256` files. The official unified bundle should preserve the canonical Android v0.1.12 APK and its signing identity.

# LouderMe Desktop v0.1.16 — integrated branding, repaired About and interactive EQ

Windows-only visual maintenance release. The audio processing contract, seven EQ center frequencies, 100–250% boost math, Equalizer APO dependency and signed Android APK are unchanged.

## Corrections
- **About actually opens with content:** replace the combination of auto-sized Panels and docked top children that collapsed all author/product/update/legal cards into skinny blank strips with a single scroll owner and a full-width card table. Explicit card minimum content heights, responsive social rows and a runtime assertion at **480/600/860 px** prevent empty About screenshots and broken scrolling.
- **No white logo sticker:** preserve the approved Michel's Lab LouderMe Option 4 SVG geometry and lettering but derive a transparent dark-theme raster at Windows build time by changing *only* the canonical navy text and muted slogan to readable light text. The icon/logo geometry, blue waveform, and blue `Me` remain official; Main, Splash and About share the same embedded dark asset, over existing dark surfaces.
- **Visual seven-band EQ:** new graphic with response curve, shaded frequency response, 10/5/0/−5/−10 dB grid, seven draggable frequency faders, band readouts, keyboard arrow adjustments and a collapsed optional numeric 0.5 dB fine-tuning panel. User interactions still update the **existing** NumericUpDown events, settings, presets and Equalizer APO pipeline.
- **Safe locked state:** new graphical controls disable whenever Equalizer APO is unavailable or when the temporary listening diagnostic runs; visualizations never claim to prove physical sound.

## Acceptance gates
Only stable **Windows** v0.1.16, no RC. Merge/publish only after exact-head Windows CI passes real instantiated About assertions, SVG-derived transparent raster/logo contract, WinForms build, audio/settings/Developer tests, installed Setup launch and actual Home/About screenshot evidence. The unified distributor must separately verify four new Windows artifacts and two existing Android v0.1.12 artifacts plus SHA-256s, and update both feeds; no earlier binary replacement.

Audio caveat: Equalizer APO must be attached to the physical output device; virtual native driver and real physical gain remain unverified.

## Actual Windows screenshot review
The candidate's real running 600×520 and 900×700 About captures revealed two extra issues missed by layout-only CI: truncated narrow-viewport product copy and an opaque magenta rectangle in the Michel's Lab image area. The hero description now wraps responsively, and studio attribution is native readable text with no opaque swatch. The screenshot pipeline now **requires six screenshots** (Home/About/Equalizer at two viewport sizes), including a scrolled live graphical EQ frame, with exact binary/SHA binding.

## Disabled-preset dark UI
Real EQ screenshots exposed a Windows-native white ComboBox whenever Equalizer APO is not installed. The actual preset selector remains event-connected but is hidden in the inactive/temporary-diagnostic state, with a dark surface showing the saved preset and an explicit inactive label. No audio controls are re-enabled just to improve color; the real ComboBox returns when processing is available.

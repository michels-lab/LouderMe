## Limitations

This visual correction does **not** certify audible system-wide gain, calibrated acoustic decibels, real hardware latency, Equalizer APO attachment or any native virtual driver. Windows Boost/EQ remain dependent on correctly configured Equalizer APO; this version does not introduce any new audio recording or change Windows default playback devices. No release candidates, no modifications to other app projects.

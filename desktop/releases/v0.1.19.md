# LouderMe Desktop v0.1.19 — Global Boost 100–300%

**Stable Windows maintenance candidate** for the existing Windows/Equalizer APO path. Replaces Desktop 0.1.18 after the exact-source release gates pass. The supported system output volume remains 0–100%; the separate Global Boost target now reaches 300%.

## Changes

- Global Boost slider and quick actions now include **275% and 300%**, with fine adjustment throughout 100–300%.
- At 300%, the theoretical low-level post-mix amplitude gain is **+9.54 dB**. This is a signal gain target, **not** a promise of 3× perceived loudness or distortion-free acoustic output.
- Stored Boost preferences, startup restoration, gain mathematics and animated wave indicator all accept the new maximum rather than silently reducing it to 250%.
- Equalizer APO config generates `Preamp: +9.54 dB` for enabled 300% Boost. The executable self-test writes/reads an isolated APO fixture to prove this integration. The seven-band EQ and saved user settings remain supported.
- The opt-in experimental C++ DSP and Windows laboratory bridge now accept 300% in generic command paths, with PCM bounded-output tests. **Physical-route diagnostic probes still impose their separate 150% maximum.**

## Shipping checks and limitations

The official Windows release pipeline must build .NET 10 x64, verify canonical branding, check the real WinForms UI, test on-disk APO configuration, build Setup + Portable, verify SHA-256 and install/launch/uninstall the resulting installer. Do not publish or promote the candidate if any gate fails.

Windows Global Boost still requires **Equalizer APO installed and attached to the output device**. The standalone signed virtual Windows audio driver is **not included**; output gain on each real PC remains unverified without physical testing (issues #48 and #74). Positive Boost may cause clipping/limiting on loud material; raise levels gradually and protect hearing. No unverified Authenticode-signature claim, RC or beta.

# LouderMe Desktop v0.1.2

Stable Windows installer-experience hotfix by **Michel's Lab**.

## What's changed
- The normal Windows download is now clearly the **LouderMe Setup** installer.
- The secondary standalone build is explicitly named **LouderMe Portable**.
- Installer wizard visuals are generated from the canonical LouderMe identity instead of using a generic setup presentation.
- Installer text supports English and Spanish.
- The installer keeps the optional **Start LouderMe with Windows** task.
- Windows CI now performs a real silent install, verifies `LouderMe.exe` and the uninstaller, then uninstalls cleanly.
- Public release publishing understands and preserves the explicit `LouderMe-Portable-vX.Y.Z.exe` naming.

## Files
- Recommended: `LouderMe-Setup-v0.1.2.exe`
- Optional portable: `LouderMe-Portable-v0.1.2.exe`
- SHA-256 checksum files are published for both.

## Audio behavior
This hotfix does not change the LouderMe audio engine. Native 0–100 Windows endpoint volume remains separate from APO-backed Global Boost 100–250%, and the existing 7-band EQ is preserved.

## Windows trust
Authenticode publisher signing is not configured yet. Windows can therefore still show **Unknown publisher** or SmartScreen even when the artifact matches its published SHA-256 checksum.

## Validation boundary
Repository CI must pass the .NET build, branding/About/updater/APO contracts, portable packaging, branded Inno Setup build and real install/uninstall smoke test before this release is merged or published.

Physical endpoint attachment, reboot behavior and audible 100/150/200/250% behavior remain real-Windows-machine checks.

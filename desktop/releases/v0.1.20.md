# LouderMe Desktop v0.1.20 — salidas específicas y Boost 300% confiable

**Stable Windows x64 Setup + Portable release for in-person acceptance.** Replaces Desktop v0.1.19. Normal Windows device volume stays **0–100%**. Global Boost target stays **100–300%** via the existing Equalizer APO backend. No RC or new Developer Edition.

## Funciones y correcciones

- **Seleccionar bocinas/USB/Bluetooth/HDMI para volumen y mute:** la tarjeta DEVICE VOLUME ofrece `Follow Windows default output` o un dispositivo de reproducción activo identificado por Windows. Permite ajustar **únicamente volumen/mute** del dispositivo seleccionado sin cambiar la salida predeterminada de Windows.
- **Evita volumen accidental en otro dispositivo:** si la salida elegida desaparece, conserva su identidad como no disponible, deshabilita sus controles y no transfiere cambios a las bocinas. Si vuelve el mismo endpoint, recupera el control. La elección queda guardada en el perfil local con escritura atómica, invalidando resultados de escucha y arrastres anteriores cuando cambia la salida.
- **Slider de Boost sin cambios perdidos:** al soltar el ratón, terminar una edición con teclado, perder el foco, dejar de editar o cerrar la ventana, confirma el valor final 100–300%; mientras se arrastra no escribe repetidamente Equalizer APO. Los presets rápidos siguen aplicándose de inmediato.
- Se conserva el ecualizador de siete bandas, persistencia del Boost, la prueba opcional de atenuación -18 dB y la señal +9.54 dB configurada para Boost 300% **cuando Equalizer APO está realmente instalado y asociado con la salida en uso**.

## Publicación segura y prueba instalada

El workflow debe compilar .NET 10 Windows x64, ejecutar pruebas APO/preferencias y WinForms, crear Portable y Setup con SHA-256, **instalar/abrir/desinstalar el Setup**, capturar Home/About/EQ del ejecutable instalado y vincular las capturas al hash de los binarios antes de publicar. Tras la publicación, comprobar el selector con 2 dispositivos reales, pérdida/restauración de Bluetooth/USB, slider Boost 300% con teclado/ratón, reinicio de la app y funcionamiento audible de Equalizer APO en la salida elegida.

El selector de salida **no** enruta audio entre aplicaciones ni instala un nuevo motor DSP. La ruta virtual nativa sin Equalizer APO sigue siendo experimental, requiere hardware/VM y driver validado (issue #48), y **no** forma parte de los instaladores de este lanzamiento. El paquete no equivale a aprobación de Microsoft Store, prueba física automatizada de aumento acústico ni certificación Authenticode. Subir la ganancia gradualmente para evitar picos o distorsión.

La distribución oficial unificada se publica solo cuando los seis assets de Android y Windows, sus checksums y las etiquetas de origen estén verificados; las URLs de actualización se cambian únicamente después de esa comprobación.

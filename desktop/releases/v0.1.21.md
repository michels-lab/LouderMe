# LouderMe Desktop v0.1.21 — selector de salida rediseñado

**Release estable de Windows x64, sin RC ni Developer Edition nueva.** Reemplaza Windows Desktop v0.1.20. Android Direct permanece en **v0.1.15** (`versionCode 16`); no se recompila ni modifica la APK.

## Mejoras visibles

- **Selector de audio completamente oscuro**: se eliminó el desplegable blanco nativo de WinForms; ahora la tarjeta usa un control personalizado en la paleta de LouderMe, bordes redondeados, estado `DEFAULT`, `MANUAL` u `OFFLINE`, y menú de dispositivos temático.
- **Jerarquía simplificada**: el nombre del dispositivo se muestra una sola vez, con icono para bocinas/audífonos/Bluetooth/USB/HDMI, estado de conexión y una fila clara de `MEDIA VOLUME` con porcentaje y slider. La explicación larga fue sustituida por una nota compacta y ayuda contextual.
- **Modo predeterminado independiente**: `Follow Windows default output` se configura fuera del listado de dispositivos. Al seleccionar una salida específica se activa el modo manual; al volver a seguir Windows, se conserva la selección previa para recuperarla solo si sigue activa.
- **Accesibilidad**: menú y selector navegables con mouse y teclado (Enter/Espacio/flecha abajo), nombre descriptivo y truncamiento visual de nombres largos.

## Seguridad y compatibilidad

Se mantiene el control 0–100 % de volumen/mute por ID exacto de endpoint; si la bocina elegida se desconecta, el programa no transfiere ajustes a otra salida. No cambia el dispositivo predeterminado del sistema ni conecta automáticamente Equalizer APO. Se conservan Boost 100–300 %, el ecualizador de siete bandas y el backend convencional de Equalizer APO. Se corrigió que abrir la aplicación con un endpoint manual desconectado pudiera impedir recuperar los ajustes de Boost/EQ guardados.

## Compilación y aceptación

El pipeline estable debe compilar y probar WinForms/.NET 10 x64, contratos de salida y preferencias, formato compacto, generar Setup y Portable con SHA-256, instalar y abrir el Setup, capturar Home/About/EQ del ejecutable definitivo y desinstalar correctamente antes de publicar la etiqueta `desktop-v0.1.21`. Después, el publicador unificado debe verificar el mismo Android Direct v0.1.15 ya firmado y sus dos archivos, junto a los cuatro de Windows, antes de ofrecer el nuevo canal `louderme-android-v0.1.15-desktop-v0.1.21`.

**Prueba personal recomendada:** abrir el menú oscuro con el ratón y el teclado, comprobar modo Windows predeterminado/manual, cambiar de bocinas a Bluetooth/USB, desconectar y reconectar, verificar que mute/volumen nunca afecten a otro dispositivo, y probar Boost 300 % con Equalizer APO conectado a la salida correcta. No se promete mejora acústica universal ni se incluye el controlador virtual experimental (#48). No es una publicación en Microsoft Store.

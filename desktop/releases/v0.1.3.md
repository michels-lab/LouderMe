# LouderMe Desktop v0.1.3

Stable Windows installer-parity hotfix by **Michel's Lab**.

## What's changed
- The LouderMe installer now uses the same clean **modern Inno Setup wizard style as FoamLens**.
- Removes the custom left-side and small wizard banner images that made LouderMe look like a different installer family.
- Keeps the official LouderMe application icon, product name/version and Michel's Lab publisher identity.
- Preserves English/Spanish installer text.
- Preserves the optional desktop shortcut and **Start LouderMe with Windows** tasks.
- CI now fails if custom `WizardImageFile` or `WizardSmallImageFile` entries are reintroduced.

## Files
- Recommended: `LouderMe-Setup-v0.1.3.exe`
- Optional portable: `LouderMe-Portable-v0.1.3.exe`
- SHA-256 checksum files are published for both.

## Audio behavior
No audio-engine behavior changes are included. Native Windows endpoint volume, APO-backed Global Boost 100–250% and the 7-band EQ are preserved.

## Windows trust
Authenticode publisher signing is still not configured. Windows may therefore show **Unknown publisher** or SmartScreen despite checksum verification.

## Validation
Repository CI must build the clean FoamLens-style installer and complete a real silent install/uninstall smoke test before publication.

# LouderMe Desktop v0.1.4

Stable Windows startup-crash hotfix by **Michel's Lab**.

## Fixed
- Fixes a production crash where LouderMe installed successfully but closed immediately on startup.
- Root cause: custom WinForms controls used `Color.Transparent` without enabling `ControlStyles.SupportsTransparentBackColor`.
- Enables transparent background support on all affected custom controls:
  - `WaveformMarkControl`
  - `AudioPulseControl`
  - `EqCurveControl`
  - `SocialGlyphControl`

## Startup diagnostics
- Adds a top-level startup crash log at:
  `%LOCALAPPDATA%\Michel's Lab\LouderMe\startup-crash.log`
- Production startup failures now show the saved diagnostic path instead of silently disappearing.

## Regression coverage
- Windows CI now installs the real Setup, launches the installed `LouderMe.exe`, requires it to remain alive, then closes and uninstalls it.
- The stable release workflow carries the same installed-runtime gate.
- CI also rejects removal of the required transparent-background WinForms style.

## Preserved
- FoamLens-style clean modern installer.
- LouderMe icon, Michel's Lab publisher identity, English/Spanish setup text, desktop shortcut and Start with Windows.
- Global Boost 100–250%, Equalizer APO integration, 7-band EQ and Desktop updater.

- Optional portable: `LouderMe-Portable-v0.1.4.exe`

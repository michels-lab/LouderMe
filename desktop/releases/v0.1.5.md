# LouderMe Desktop v0.1.5

Stable Windows release by Michel's Lab.

## New
- Active Windows playback endpoint volume and mute now resynchronize periodically, including external changes.
- Device Volume remains the Windows master endpoint level (0–100%); Global Boost stays a separate Equalizer APO gain control (100–250%).
- Michel's Lab “Tools with identity” studio slogan appears in About.

## Preserved
- Native Windows desktop application, Equalizer APO processing, seven-band EQ, updater, and clean Inno Setup installer.
- Real installed-app startup smoke test and SHA-256 checksums.

## Artifacts
- `LouderMe-Setup-v0.1.5.exe` — recommended.
- `LouderMe-Portable-v0.1.5.exe` — optional.

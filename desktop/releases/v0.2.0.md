# LouderMe Desktop v0.2.0

Stable-candidate Windows feature release by **Michel's Lab**.

## Device Volume
- Promotes **Device Volume** to an explicit 0–100% Windows master-output control.
- Continues using the real Core Audio endpoint property `AudioEndpointVolume.MasterVolumeLevelScalar`.
- Resyncs every 500 ms so changes from Windows, keyboard/media keys or other volume controls are reflected in LouderMe.
- Detects a change in the default multimedia playback endpoint and automatically switches the displayed device/volume.
- Mute remains part of Device Volume and separate from Global Boost.

## Global Boost separation
- Device Volume = real OS output level, 0–100%.
- Global Boost = LouderMe post-volume signal gain, 100–250%.
- The UI explains this distinction directly.

## Bug fixes
- Live volume polling no longer overwrites the thumb while the user is actively dragging it.
- A temporarily missing/default playback endpoint no longer prevents LouderMe from loading startup, boost or EQ state.
- Equalizer APO access/read failures are contained and surfaced in the UI rather than escaping as app crashes.
- The updater validates feed schema/product identity and closes LouderMe after launching a verified installer for a cleaner in-place update.
- Post-install launch runs as the original Windows user rather than inheriting installer elevation.
- Restores the current canonical Michel's Lab lockup asset in Desktop About and updates CI to reject the obsolete/corrupt interim asset.

## Preserved
- FoamLens-style clean installer.
- v0.1.4 startup-crash fix and installed-launch CI gate.
- Equalizer APO boost/EQ behavior, updater and Start with Windows.

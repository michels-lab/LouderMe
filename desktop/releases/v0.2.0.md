# LouderMe Desktop v0.2.0

Stable-candidate Windows feature release by **Michel's Lab**.

## Device Volume
- Promotes **Device Volume** to an explicit 0–100% Windows master-output control.
- Continues using the real Core Audio endpoint property `AudioEndpointVolume.MasterVolumeLevelScalar`.
- Resyncs every 500 ms so changes from Windows, keyboard/media keys or other volume controls are reflected in LouderMe.
- Detects a change in the default multimedia playback endpoint and automatically switches the displayed device/volume.
- Mute remains part of Device Volume and separate from Global Boost.

## Global Boost separation
- Device Volume = real OS output level, 0–100%.
- Global Boost = LouderMe post-volume signal gain, 100–250%.
- The UI explains this distinction directly.

# LouderMe Android v0.1.10

Stable release by Michel's Lab.

## New
- Real Android media stream volume control (0–100%), distinct from Global Boost 100–250%.
- Media volume automatically resynchronizes while the app is in the foreground when the system or hardware controls change.
- Michel's Lab “Tools with identity” studio slogan in About.

## Preserved
- Equalizer, boost presets, updater, About navigation and Play/Direct distribution separation.
- Existing stable Direct signing identity; updates require the same release certificate.

## Distribution
- Package: `com.michelslab.louderme`
- versionName: `0.1.10`
- versionCode: `11`

## Validation boundary
CI builds Android Play and Direct variants. Real device media-route and audible behavior remain subject to post-release physical testing.

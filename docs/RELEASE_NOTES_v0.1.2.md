# LouderMe v0.1.2 — 250% Boost

This release extends the manual LouderMe boost range to **250%** after the v0.1.1 session-0 path was reported to audibly work on the target Samsung device.

## New
- 225% quick boost.
- 250% quick boost.
- 100–250% fine slider.
- Two-row quick-control layout.
- Gain tests through 250%.

## Signal-gain values
- 150% ≈ +3.52 dB target signal gain.
- 200% ≈ +6.02 dB target signal gain.
- 225% ≈ +7.04 dB target signal gain.
- 250% ≈ +7.96 dB target signal gain.

These are **digital signal-gain values**, not loudspeaker dB SPL measurements. Real acoustic output depends on the phone/speaker/headphones, DSP, limiter/compressor behavior, source content and listening conditions.

## Compatibility
Android still deprecates global insert effects on audio session 0. The target Samsung device works audibly with the current path, but LouderMe keeps explicit unsupported/degraded/error states for other devices.
